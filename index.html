📋 Procedure Guide

1. RFID Tag Miss Report

Transma File (Required): Date, Station, Loco Id, Direction, RFID, Tag Link Info, TIN, Abs Loc

Tag_Linking_data File (Optional): Nxt RFID Id and Dist and Dir sequence

Mode 1 – Transma Only: All missing types shown. Actual Tag column hidden.

Mode 2 – Both Files: All missing types shown with Actual Tag computed from TKG sequences for BothTagMissing. MainTagMissing & DuplicateTagMissing Actual Tag = RFID value.

2. Station Health Report

Columns: Date, Time, Station, Event Name, Event Info
Computes hourly Rev/Fwd Power, Temp, PA Current. Forward-fills missing values.

3. Station RX Report

Columns: Date, Station, Event Name, Event Info
Totals Radio-1 and Radio-2 RX packet counts. Flags defective radios.

4. Loco RX Report

Columns: Date, Traffic Dir, Cur Station ID, Loco ID, RadRxPktCnt, RadID

5. GPRS Faults Report

Columns: Date, Time, Station, Module, Fault Type, Fault Msg
Filters active unresolved module faults.
